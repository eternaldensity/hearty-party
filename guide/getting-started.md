# Getting Started

## Creating a Game

1. One player **creates a game** and shares the 4-letter room code.
2. Other players **join** by entering the code and a display name.
3. The host configures settings and presses **Start Game** when everyone is in.

## Game Settings

| Setting | Default | Description |
|---------|---------|-------------|
| Total Rounds | 15 | How many rounds the game lasts |
| Cutthroat Mode | Off | Enables stealing, sabotage, and jealousy mechanics |

## How to Win

There are two ways to win:

### Total Affection (Standard)

At the end of all rounds, the player with the **highest total affection** across all five characters wins. Your total affection is the sum of your individual affection scores with each character (each ranging from 0 to 100).

**Tiebreaker:** Highest single-character affection.

### Confession (Instant Win)

If any player reaches **100 affection** with a single character at any point during the game, a **Confession** is triggered and that player wins immediately. This is extremely difficult to achieve, requiring a perfect combination of dialogue choices, items, and minigame rewards focused on a single character.

When a Confession happens, the game ends right away and the confessing player is declared the winner regardless of other players' total affection.
