# Round Flow

Each round follows this sequence:

1. **Round Start** — The round number is displayed.
2. **Dice Phase** — All players roll simultaneously (tap/click to roll). If you don't roll within 3 seconds, the game rolls for you. Roll range: **1–6**.
3. **Move Phase** — Players move one at a time. If you hit a branch point, you choose which path to take (10-second timer, defaults to the main path).
4. **Space Phase** — Each player's landed space activates in order. You might get a dialogue choice, open a shop, or trigger an event.
5. **Minigame Phase** — A random minigame is selected. All players see a 5-second intro with the rules, then play the minigame together. Results and rewards are shown afterwards.
6. **Round End** — Standings are shown, then the next round begins.

After all rounds are complete, the game ends and final standings are revealed.

**Early end:** If any player reaches 100 affection with a single character during the space phase or after minigame rewards, the game ends immediately with a [Confession](getting-started.md#confession-instant-win) victory.
