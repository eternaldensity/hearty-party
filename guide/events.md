# Random Events

Landing on an Event space triggers one of these random outcomes:

| Event | Effect | Who's Affected |
|-------|--------|----------------|
| Found a shiny coin | +2 tokens | You |
| Warm breeze carries sweet words | +3 affection (random character) | You |
| Tripped in front of everyone | -2 affection (random character) | You |
| Flower petals rain from the sky | +2 affection (random character) | Everyone |
| Mysterious benefactor gives a gift | +1 token | Everyone |
| Someone ate another player's snack | -2 affection (random character) | A random other player |
| Secret admirer note | +4 affection (random character) | You |
| Lucky day — extra tokens | +3 tokens | You |
| Someone spread gossip about you | -3 affection (random character) | You |
| Group photo — smiles all around | +1 affection (random character) | Everyone |
| Dropped your wallet | -2 tokens | You |
| Impromptu dance party | +2 affection (random character) | Everyone |

**Note:** The Shield Brooch blocks negative *affection* effects (like gossip or tripping), but not token losses.
